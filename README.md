# SocialBook

SocialBook is a modern, user-friendly social networking platform designed to help you connect, share, and engage with friends and the wider community. Built with PHP, it features a clean interface, responsive design, and essential social features such as posting, commenting, messaging, following, and more.

## Features

- User registration and login
- Create, edit, and delete posts
- Comment on posts
- Like and follow functionality
- Direct messaging between users
- Profile management
- Admin controls for moderation
- Responsive and accessible design

## Getting Started

### Prerequisites
- PHP 7.4 or above
- MySQL or compatible database
- Web server (e.g., Apache, Nginx)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/SocialBook.git
   ```
2. Set up your web server to serve the project directory.
3. Import the provided SQL database schema (if available).
4. Configure database credentials in `classes/connect.php`.
5. Access the site via your browser at `http://localhost/SocialBook`.

## Folder Structure

- `index.php` – Home page
- `login.php`, `signup.php` – Authentication
- `mainboard.php` – Main feed
- `profile.php` – User profiles
- `post.php`, `comment.php` – Posting and commenting
- `message.php` – Messaging
- `adminPage.php`, `adminLogin.php` – Admin features
- `classes/` – PHP classes for backend logic
- `js/` – JavaScript files
- `assets/` – Images and static assets
- `uploads/` – User-uploaded content
